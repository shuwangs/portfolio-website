## 3907. Count Smaller Elements With Opposite Parity

```txt
You are given an integer array nums of length n.

The score of an index i is defined as the number of indices j such that:

- i < j < n
- nums[j] < nums[i]
- nums[i] and nums[j] have different parity (one is even and the other is odd).

Return an integer array answer of length n, where answer[i] is the score of index i.
```

### First Attempt

I grouped the indices by parity. For each number, I scanned the opposite group and counted the indices that were to its right and had a smaller value.

```python
from collections import defaultdict


class Solution:
    def countSmallerOppositeParity(self, nums: list[int]) -> list[int]:
        parities = defaultdict(list)

        for i, num in enumerate(nums):
            if num % 2 == 0:
                parities["even"].append(i)
            else:
                parities["odd"].append(i)

        ans = []
        for i, num in enumerate(nums):
            count = 0
            if num % 2 == 0:
                for idx in parities["odd"]:
                    if idx > i and nums[idx] < num:
                        count += 1
            else:
                for idx in parities["even"]:
                    if idx > i and nums[idx] < num:
                        count += 1

            ans.append(count)

        return ans
```

This looked good to me at first, but it timed out. Building the groups takes `O(n)` time. The expensive part is scanning the opposite group for every number. If about half the numbers are even and half are odd, each scan checks about `n / 2` indices, so the worst-case time is `O(n²)`.

### SortedList

What clicked for me was scanning **from right to left**. When I reach index `i`, every number I've already added is to its right. So `j > i` is already taken care of.

I keep two sorted lists, one for even numbers and one for odd numbers. For each number, I use `bisect_left` on the opposite list to count how many values are smaller. Then I add the current number to its own list.

`bisect_left(x)` finds the first position where `x` could go while keeping the list sorted. For example, if `odds = [1, 3, 3]`, then `odds.bisect_left(4)` returns `3`. There are three values before that position, and all three are smaller than `4`. That's why I can use the returned index directly as the answer.

```python
from sortedcontainers import SortedList


class Solution:
    def countSmallerOppositeParity(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [0] * n
        evens = SortedList()
        odds = SortedList()

        for i in range(n - 1, -1, -1):
            num = nums[i]

            if num % 2 == 0:
                ans[i] = odds.bisect_left(num)
                evens.add(num)
            else:
                ans[i] = evens.bisect_left(num)
                odds.add(num)

        return ans
```
