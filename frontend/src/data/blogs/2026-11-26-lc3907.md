## 3907 Count Smaller Elements With Opposite Parity
```txt
You are given an integer array nums of length n.

The score of an index i is defined as the number of indices j such that:

- i < j < n
- nums[j] < nums[i]
- nums[i] and nums[j] have different parity (one is even and the other is odd).
Return an integer array answer of length n, where answer[i] is the score of index i.
```

- First Attemp:
```py
class Solution:
    def countSmallerOppositeParity(self, nums: list[int]) -> list[int]:
        parities = defaultdict(list)

        for i, num in  enumerate(nums):
            if num % 2 == 0:
                parities["even"].append(i)

            else:
                parities["odd"].append(i)
        
        ans = []
        for i, num in enumerate(nums):
            count = 0
            if num % 2 == 0:
                all_odds = parities.get("odd")
                if all_odds:
                    for idx in all_odds:
                        if idx > i and nums[idx] < num:
                            count += 1

                ans.append(count)
            else:
                all_even = parities.get("even")
                if all_even:
                    for idx in all_even:
                        if idx > i and  nums[idx] < num:
                            count += 1

                ans.append(count)    

        return ans
```

- Sorted List + Binary Indexed Tree
> - Actually the key is to loop from right to left side, then you can get the j > i
> and with sorted List its easy to find the num
> - The second is bisect_left function:
> `bisect.bisect_left(a, x, lo=0, hi=len(a), *, key=None)
Locate the insertion point for x in a to maintain sorted order.`
```py
class Solution:
    def countSmallerOppositeParity(self, nums: list[int]) -> list[int]:
        n = len(nums)
        ans = [0] * n
        evens = SortedList()
        odds = SortedList()

        for i in range(len(nums) -1, -1, -1) :
            num = nums[i]

            if num % 2 == 0:
                ans[i] = odds.bisect_left(num)
                evens.add(num)
            
            else:
                ans[i] = evens.bisect_left(num)
                odds.add(num)

        return ans

```
